# Project 1 LED Blink

### **1.説明**

![](media/A40.jpeg)

初心者や愛好家向けに、LED Blinkは基本的なプログラムです。LEDはlight emitting diodes（発光ダイオード）の略で、Ga、As、P、Nなどの化学化合物で構成されています。

テストコードの遅延時間を変えることで、LEDはさまざまな色で点滅できます。制御時には、GNDとVCCに電源を入れ、S端子が高レベルの場合はLEDが点灯し、そうでなければ消灯します。

### **2.仕様**

- 制御インターフェース：デジタルポート

- 動作電圧：DC 3.3-5V

- ピン間隔：2.54mm

- LED表示色：赤
