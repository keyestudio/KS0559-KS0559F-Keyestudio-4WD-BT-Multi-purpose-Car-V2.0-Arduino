# 3. Instalación del controlador

## 3.1 Sistema Windows

### 1 Comprobación del controlador

1. Conecte la placa base al ordenador.

![](./media/A1.jpg)

2. Abra el Administrador de dispositivos. Si aparece el mensaje **"Silicon Labs CP210x USB to UART Bridge (COMx)"**, significa que el controlador ya está instalado, por favor omita la sección **"Instalación del controlador"**.

![](./media/A2.gif)

### 2 Instalación manual del controlador

1. Descarga del controlador

- Sistema Windows: [Controlador para sistema Windows](./Windows.7z)

2. Conecte la placa base al ordenador, abra el Administrador de dispositivos. Si aparece un signo de exclamación amarillo delante del controlador en la imagen, significa que el controlador no está instalado. Descargue el controlador e instálelo manualmente.

![](./media/A3.gif)

## 3.2 Sistema MAC

### 1 Comprobación del controlador

Conecte la placa de desarrollo al ordenador, y seleccione el puerto de la placa desde [Herramientas] ---> [Puerto] (Nota: Si no puede confirmar cuál es el puerto de la placa de desarrollo, conecte la placa base y tome una foto para registrar todos los puertos, luego desconecte la placa y tome otra foto para registrar todos los puertos, compare para encontrar los puertos que desaparecieron, el puerto que desaparece al desconectar la placa es el puerto de la placa. Seleccione ese puerto en la línea). Si no reconoce el puerto, pruebe a cambiar el puerto USB del ordenador o el cable USB para que reconozca el puerto. Si sigue sin funcionar, siga los pasos siguientes para instalar el controlador.

![](./media/A4.png)

### 2 Instalación manual del controlador

1. Descarga del controlador

Sistema Mac: [Controlador para sistema Mac](./Mac.7z)

2. Haga doble clic para descomprimir el paquete zip del controlador descargado

![](./media/A5.png)

![](./media/A6.png)

![](./media/A7.png)

3. Después, continúe haciendo clic en **"Next"** para instalar hasta que la instalación finalice

![](./media/A8.png)

En este punto, el puerto será reconocido al volver a conectar la placa.

4. Luego, abra el Arduino IDE, haga clic en “Herramientas”, seleccione la placa Arduino Uno y el puerto reconocido de la placa de desarrollo.

![](./media/A9.png)

5. Haga clic ![image-20250417085312966](./media/A10.png) para subir el código y aparecerá “Done uploading”.

![](./media/A11.png)
