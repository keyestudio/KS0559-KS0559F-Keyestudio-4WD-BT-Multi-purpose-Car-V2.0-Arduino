# 3. Treiberinstallation

## 3.1 Windows-System

### 1 Überprüfung des Treibers

1. Verbinden Sie das Motherboard mit dem Computer.

![](./media/A1.jpg)

2. Öffnen Sie den Geräte-Manager. Wenn die Meldung **"Silicon Labs CP210x USB to UART Bridge (COMx)"** erscheint, ist der Treiber bereits installiert. Bitte überspringen Sie in diesem Fall den Abschnitt **"Treiberinstallation"**.

![](./media/A2.gif)

### 2 Manuelle Treiberinstallation

1. Treiber herunterladen

- Windows-System: [Windows-System-Treiber](./Windows.7z)

2. Verbinden Sie das Motherboard mit dem Computer und öffnen Sie den Geräte-Manager. Wenn vor dem Treiber ein gelbes Ausrufezeichen angezeigt wird, ist der Treiber nicht installiert. Bitte laden Sie den Treiber herunter und installieren Sie ihn manuell.

![](./media/A3.gif)

## 3.2 MAC-System

### 1 Überprüfung des Treibers

Verbinden Sie das Entwicklungsboard mit dem Computer und wählen Sie im Menü [Tools] ---> [Port] den Port des Entwicklungsboards aus (Hinweis: Wenn Sie den Port des Entwicklungsboards nicht sicher identifizieren können, verbinden Sie das Motherboard und machen Sie ein Foto aller Ports. Trennen Sie dann das Entwicklungsboard, machen Sie erneut ein Foto aller Ports und vergleichen Sie die Bilder, um den verschwundenen Port zu finden. Der verschwundene Port ist der Port des Boards. Wählen Sie diesen Port anschließend aus). 

Falls der Port nicht erkannt wird, wechseln Sie den USB-Anschluss am Computer oder das USB-Kabel und versuchen Sie es erneut. Wenn das Problem weiterhin besteht, folgen Sie den nachstehenden Schritten zur Treiberinstallation.

![](./media/A4.png)

### 2 Manuelle Treiberinstallation

1. Treiber herunterladen

   Mac-System: [Mac-System-Treiber](./Mac.7z)

2. Doppelklicken Sie auf das heruntergeladene ZIP-Paket, um es zu entpacken.

![](./media/A5.png)

![](./media/A6.png)

![](./media/A7.png)

3. Klicken Sie anschließend auf **"Next"**, um die Installation fortzusetzen, bis diese abgeschlossen ist.

![](./media/A8.png)

Anschließend kann der Port durch erneutes Einstecken des Boards erkannt werden.

4. Öffnen Sie dann die Arduino IDE, klicken Sie auf „Tools“, wählen Sie das Board Arduino Uno und den erkannten Port des Entwicklungsboards aus.

![](./media/A9.png)

5. Klicken Sie auf ![image-20250417085312966](./media/A10.png), um den Code hochzuladen. Es erscheint die Meldung „Done uploading“.

![](./media/A11.png)
