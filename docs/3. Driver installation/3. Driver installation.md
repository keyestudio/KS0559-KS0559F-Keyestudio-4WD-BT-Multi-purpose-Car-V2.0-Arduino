# 3. Installation du pilote

## 3.1 Système Windows

### 1 Vérification du pilote

1. Connectez la carte mère à l’ordinateur.

![](./media/A1.jpg)

2. Ouvrez le Gestionnaire de périphériques. Si le message **"Silicon Labs CP210x USB to UART Bridge (COMx)"** apparaît, cela prouve que le pilote est installé, veuillez passer la partie **"Installation du pilote"**.

![](./media/A2.gif)

### 2 Installation manuelle du pilote

1. Téléchargement du pilote

- Système Windows : [Pilote système Windows](./Windows.7z)

2. Connectez la carte mère à l’ordinateur, ouvrez le gestionnaire de périphériques. Si un point d’exclamation jaune apparaît devant le pilote comme sur l’image, cela signifie que le pilote n’est pas installé. Veuillez télécharger le pilote et l’installer manuellement.

![](./media/A3.gif)

## 3.2 Système MAC

### 1 Vérification du pilote

Connectez la carte de développement à l’ordinateur, puis dans [Outils] ---> [Port], sélectionnez le port de la carte de développement (Note : si vous ne pouvez pas identifier quel port correspond à la carte, connectez la carte mère et prenez une photo pour enregistrer tous les ports, puis débranchez la carte et reprenez une photo pour enregistrer tous les ports, comparez ensuite pour trouver les ports disparus. Le port disparu correspond à la carte. Débranchez ensuite la carte mère, puis sélectionnez ce port dans la liste). Si le port n’est pas reconnu, essayez de changer de port USB sur l’ordinateur ou de câble USB, puis réessayez. Si cela ne fonctionne toujours pas, suivez les étapes ci-dessous pour installer le pilote.

![](./media/A4.png)

### 2 Installation manuelle du pilote

1. Téléchargement du pilote

Système Mac : [Pilote système Mac](./Mac.7z)

2. Double-cliquez pour décompresser le fichier zip du pilote téléchargé

![](./media/A5.png)

![](./media/A6.png)

![](./media/A7.png)

3. Ensuite, cliquez sur **"Next"** pour continuer l’installation jusqu’à ce qu’elle soit terminée

![](./media/A8.png)

À ce stade, le port sera reconnu en rebranchant la carte.

4. Ensuite, ouvrez l’IDE Arduino, cliquez sur “Outils”, sélectionnez la carte Arduino Uno et le port de la carte de développement reconnu.
