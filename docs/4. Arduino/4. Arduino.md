## 4.2 Téléchargement du logiciel

Lorsque nous recevons la carte de contrôle, nous devons d'abord télécharger l'IDE Arduino et le pilote.

Vous pouvez télécharger l'IDE Arduino depuis le site officiel : <https://www.arduino.cc/en/software>.

Il existe plusieurs versions d'Arduino, téléchargez simplement une version adaptée à votre système. Nous prendrons le système WINDOWS comme exemple pour vous montrer comment télécharger et installer.

![](./media/A1.gif)

Il vous suffit de cliquer sur JUSTDOWNLOAD, puis de cliquer sur le fichier téléchargé pour l'installer.

Et lorsque le fichier ZIP est téléchargé, vous pouvez directement le décompresser et le lancer.

![](./media/A2.gif)

## 4.4 Ajouter une bibliothèque

Qu'est-ce qu'une bibliothèque ?

Les bibliothèques sont une collection de code qui facilite la connexion à un capteur, un affichage, un module, etc.

Il existe des centaines de bibliothèques supplémentaires disponibles sur Internet à télécharger.

Nous allons vous présenter la manière la plus simple d'ajouter des bibliothèques.
