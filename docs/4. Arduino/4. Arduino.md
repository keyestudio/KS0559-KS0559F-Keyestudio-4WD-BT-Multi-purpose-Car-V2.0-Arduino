## 4.2 Software herunterladen

Wenn wir das Steuerboard erhalten, müssen wir zuerst die Arduino IDE und den Treiber herunterladen.

Sie können die Arduino IDE von der offiziellen Website herunterladen: <https://www.arduino.cc/en/software>.

Es gibt verschiedene Versionen für Arduino, laden Sie einfach eine passende Version für Ihr System herunter. Wir nehmen das WINDOWS-System als Beispiel, um Ihnen zu zeigen, wie man herunterlädt und installiert.

![](./media/A1.gif)

Sie müssen nur auf JUSTDOWNLOAD klicken und dann die heruntergeladene Datei anklicken, um sie zu installieren.

Und wenn die ZIP-Datei heruntergeladen ist, können Sie sie direkt entpacken und starten.

![](./media/A2.gif)

## 4.4 Bibliothek hinzufügen

Was sind Bibliotheken?

Bibliotheken sind eine Sammlung von Code, die es Ihnen erleichtert, eine Verbindung zu einem Sensor, Display, Modul usw. herzustellen.

Es gibt Hunderte von zusätzlichen Bibliotheken, die im Internet zum Download verfügbar sind.

Wir stellen Ihnen die einfachste Methode vor, um Bibliotheken hinzuzufügen.
