## 4.2 Descarga de software

Cuando recibimos la placa de control, primero necesitamos descargar Arduino IDE y el controlador.

Puede descargar Arduino IDE desde el sitio web oficial: <https://www.arduino.cc/en/software>.

Hay varias versiones para Arduino, solo descargue una versión adecuada para su sistema, tomaremos el sistema WINDOWS como ejemplo para mostrarle cómo descargar e instalar.

![](./media/A1.gif)

Solo necesita hacer clic en JUSTDOWNLOAD, luego hacer clic en el archivo descargado para instalarlo.

Y cuando se descargue el archivo ZIP, puede descomprimirlo directamente y ejecutarlo.

![](./media/A2.gif)
